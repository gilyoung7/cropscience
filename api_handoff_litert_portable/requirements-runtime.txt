# Lightweight portable API — RUNTIME dependencies (production, FP16-only).
#
#   python3 -m venv .venv-lightweight-api
#   ./.venv-lightweight-api/bin/python -m pip install -r requirements-runtime.txt
#
# NO torch. NO tensorflow/keras. NO scikit-learn. No .pt is ever loaded.
#
# scipy IS present, but only transitively: `pip show xgboost` -> Requires: numpy,
# scipy. It is not imported by our code and cannot be removed while Stage-1 uses
# xgboost. At ~98 MB it is the single largest package in the runtime env — see
# the "remaining bottleneck" section of the report.
#
# Why each is here:
#   xgboost        Stage-1 gate, loaded via xgboost.Booster (model.json).
#                  Booster avoids the sklearn wrapper entirely — proven bit-exact
#                  vs XGBClassifier on 48/48 combos.
#   ai-edge-litert Stage-2 LiteRT/TFLite interpreter. Standalone Google wheel;
#                  requires only backports.strenum, flatbuffers, numpy, protobuf,
#                  tqdm, typing-extensions — NOT the tensorflow package.
#   numpy          numerics.
#   pandas         REQUIRED for parity, not convenience: the deployed API builds
#                  Stage-1 base X via X_df.to_numpy(), whose F-contiguous layout
#                  changes float32 reduction order in the tabular features
#                  (mean/std differ by ~3e-08/6e-08 vs C-order), which can move the
#                  alert DOY. See docs/lightweight_api_integration_report.md.
#   PyYAML         fallback_policy.yaml.
#
# Verified on macOS 26.5.1 / Apple M3 (arm64) / Python 3.12.2, 2026-07-16.

xgboost==2.1.4
